# قطار الصحراء

لعبة محاكاة قطارات ثلاثية الأبعاد تشتغل في المتصفح، مبنية بـ [three.js](https://threejs.org).

## التشغيل

افتح `index.html` في المتصفح. أو فعّل GitHub Pages للمستودع وافتح الرابط.

## وش فيها

- **8 خرائط:** الصحراء، والوادي الأحمر، والساحل، والجبال الثلجية، وصحراء الليل، ونزلة الجبل، وغابة الخريف، والمدينة.
- **13 قطار:** كهربائية وديزل وبخارية. القاطرات البخارية فيها أذرع تتحرك ودخان.
- **فيزياء:** وزن وقوة جر وفرامل ومقاومة وميل، وخروج عن السكة في المنعطفات.
- **حوادث:** العربات مربوطة بوصلات لها قوة، والسكة تمسك العربات. والعربات تصطدم بالأشجار والأعمدة والصخور والمباني.
- **صانع خرائط:** تبني الخط بسحب القطع أو برسمه بالماوس، وتحدد الطلعات والنزلات.
- **مثبت سرعة** يوصل لين 1000 كم/س، وزر **بدون حوادث**.
- **كاميرات:** الكابينة، والحرة، وجنب السكة، والطيران الحر.

## التحكم

| الزر | وش يسوي |
|---|---|
| `W` / `↑` | زيادة الجر |
| `S` / `↓` | تخفيف ثم فرامل |
| `Space` | فرامل طوارئ |
| `C` | تغيير الكاميرا |
| `X` | مثبت السرعة |
| `N` | بدون حوادث |
| `H` | البوق أو الصافرة |

في الجوال: اسحب الذراع اللي على اليمين، واستخدم الأزرار اللي على الشاشة.
